# 写真コンテストものさし

手元の写真について、応募できそうなフォトコンテストを条件照合し、過去の受賞作から読み取れる傾向を公式ギャラリーへの導線とともに整理するモバイルファーストのMVPです。

## 現在できること

- 写真を任意で端末内だけにプレビューし、画像形式・容量・画素数を確認
- 未回答を推測で埋めず、作品形態、撮影年、撮影都道府県、年齢、学生区分、活動区分、権利などを照合
- 国内74・海外／国際32の計106応募ルートを「確認範囲で不一致なし」「要確認」「明示条件に不一致」に分けて理由を表示
- 「すべて」「国内公募」「海外・国際公募」を結果画面で切り替え、分類設定を端末内に保存
- 47都道府県の地方公募調査台帳を表示し、各県で少なくとも1件の現行または次回募集を公式確認。全件網羅ではなく、締切後の次回募集への更新基準として扱う
- 第2次調査では青森・宮城・秋田・山形・茨城・栃木・群馬・千葉・東京・神奈川・富山・福井の12都県を追加
- 第3次調査では静岡・愛知・京都・和歌山・鳥取・島根・岡山・山口・愛媛・佐賀・沖縄を追加。河川・農村・森林・国立公園・県議会の小規模公募も含め、規約が不足する項目は要確認のまま扱う
- 第4次調査では石川・山梨・三重・大阪・兵庫・奈良・徳島・福岡・熊本・大分・宮崎・鹿児島を追加。町・市・県・観光協会・施設運営者の公開募集を混ぜずに記録し、Instagram・LINE・フォーム・郵送の入口を区別
- 第5次調査では、北海道・福島・関東・中部・中国・九州の小規模／広域公募15ルートと、世界から応募可能なUNESCO・European Photography Awards・Xposureの3ルートを追加。規約の全条項を取れない項目は要確認のまま保持
- 県名から作品カルテへ撮影地を入れ、市町村・施設単位の細かな撮影範囲は公式要項での確認事項として保持
- 公式フォーム、プラットフォーム、メール、ハッシュタグを応募方式として区別
- NatGeo Your Shot、PhotoVogue、Flickr、LFI Gallery、VIEWBUGなど11の常設・週次・月次のキュレーション／探索先を、締切型公募とは別枠で照合
- 探索先ごとに、手元の写真が「使える見込み」「準備・確認あり」「今回の条件外」のどれかを判定
- 撮影日、機材、SNS公開、写真サービス登録、新作撮影可否を探索先の条件に反映
- 居住・市民権の範囲、SNS投稿可否、公開アカウント可否を条件照合
- 応募資格、提出時の書き出し調整、部門候補を別の判定として表示
- 各ルートの8条項について、公式根拠の確認状態をデータに保持
- 候補の保存と入力条件をブラウザの `localStorage` に保存
- 主催者の公式受賞作ページから、傾向メモと代表作品情報を確認

写真データはアップロードしません。公開要項の解釈補助であり、最終判断は必ず各主催者の公式ページで行ってください。

## 開発

Node.js `>=22.13.0` が必要です。

```bash
npm install
npm run dev
npm run audit:data
npm test
```

- 画面: `app/page.tsx`
- スタイル: `app/globals.css`
- 公募データ: `data/opportunities.json`、`data/worldwide-opportunities.json`、`data/social-opportunities.json`、`data/domestic-opportunities.json`
- 常設・週次・月次の探索先: `data/discovery-channels.json`
- 受賞傾向データ: `data/trends.json`
- 設計根拠: `DESIGN_PLAN.md`

公開情報の確認基準日は 2026-07-24 です。公式ページ内で締切時刻が一致しない箇所や、時刻を確認できない締切は「要確認」として表示します。
