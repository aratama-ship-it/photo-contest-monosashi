# 写真コンテストものさし

手元の写真について、応募できそうなフォトコンテストを条件照合し、過去の受賞作から読み取れる傾向を公式ギャラリーへの導線とともに整理するモバイルファーストのMVPです。

## 現在できること

- 写真を端末内だけでプレビューし、画像形式・容量・画素数を確認
- 作品形態、撮影年、年齢、学生区分、プロ区分、応募料などを一度入力
- 12の応募ルートを「応募候補」「要確認」「対象外」に分けて理由を表示
- 候補の保存と入力条件をブラウザの `localStorage` に保存
- 主催者の公式受賞作ページから、傾向メモと代表作品情報を確認

写真データはアップロードしません。公開要項の解釈補助であり、最終判断は必ず各主催者の公式ページで行ってください。

## 開発

Node.js `>=22.13.0` が必要です。

```bash
npm install
npm run dev
npm test
```

- 画面: `app/page.tsx`
- スタイル: `app/globals.css`
- 公募データ: `data/opportunities.json`
- 受賞傾向データ: `data/trends.json`
- 設計根拠: `DESIGN_PLAN.md`

公開情報の確認基準日は 2026-07-22 です。
